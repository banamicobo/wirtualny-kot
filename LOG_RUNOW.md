# LOG RUNOW — WKT

Rejestr zlecen ocenionych na minus. Sucha informacja do analizy z Miko: data, zlecenie jednym zdaniem, notatka Miko jego slowami. Bez tlumaczen, bez usprawiedliwien, bez komentarza agenta. Plusow nie logujemy.

Format wpisu:

```
## RRRR-MM-DD — zlecenie jednym zdaniem
**Miko:** cytat albo „bez notatki”.
```
